Customer Shopping Behavior Analysis

An end-to-end data analytics project using Python, PostgreSQL, and Power BI to analyze customer purchasing patterns and generate business insights.

Project Overview

This project focuses on understanding customer shopping behavior, purchase trends, product performance, discount usage, and subscription patterns. The workflow includes data cleaning and exploratory data analysis in Python, business analysis using PostgreSQL, and data visualization with Power BI.

Objectives

Analyze customer purchasing and spending patterns.

Compare revenue across customer demographics.

Identify top-rated products and high-performing categories.

Evaluate discount usage and shipping preferences.

Compare subscriber and non-subscriber purchasing behavior.

Segment customers based on purchase history.

Visualize key metrics through a Power BI dashboard.

Tools and Technologies

Python — Data cleaning and exploratory data analysis

Pandas and NumPy — Data manipulation

PostgreSQL — SQL-based business analysis

SQLAlchemy — Python database connectivity

Power BI — Data visualization and dashboard development

Jupyter Notebook — Analysis environment

Dataset

The dataset contains 3,900 customer purchase records and 18 columns covering customer demographics, product information, purchase amounts, discounts, shipping methods, subscription status, and review ratings.
