# Customer_Behaviour_Analysis

📌 Project Overview

This project analyzes customer shopping behavior using transactional data containing 3,900 purchase records and 18 columns. The objective is to understand customer spending patterns, product preferences, discount usage, purchasing frequency, and subscription behavior to generate meaningful business insights.

This end-to-end data analytics project uses Python for data cleaning and exploratory data analysis (EDA), PostgreSQL for SQL-based business analysis, and Power BI for interactive data visualization.

The project demonstrates how raw customer data can be cleaned, transformed, analyzed, and presented to support data-driven business decisions.

🎯 Project Objectives
Analyze customer purchasing patterns and spending behavior.
Compare revenue generated by different customer groups.
Identify highly rated and frequently purchased products.
Understand discount usage and purchasing behavior.
Compare subscribers and non-subscribers.
Segment customers based on purchase history.
Analyze revenue contribution across different age groups.
Develop business recommendations based on analytical findings.

🛠️ Tools and Technologies
Python: Data cleaning, preprocessing, EDA, and feature engineering
Pandas: Data manipulation and transformation
NumPy: Numerical operations
Jupyter Notebook: Python analysis
PostgreSQL: Database management and SQL-based analysis
Power BI: Interactive dashboards and data visualization
GitHub: Project documentation and version control
